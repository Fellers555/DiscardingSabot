A top down tank shooter! Take control of an M1 Abrams and destroy enemy tanks. Use stealth to hide your visual presence between reloads and get the drop on enemies.

Programmer: Adrian Fellers
Artists: Ferris Solano, Karis Gong

You can play the game on itch here: https://fellers555.itch.io/discarding-sabot-pre-alpha

This project was created while learning Unity. While this is a completed gameplay prototype we plan to continue development.
